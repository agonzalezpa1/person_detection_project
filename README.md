# person_detection_project
Projet de candidature stage de fin d'études chez Cali Intelligences
Fait par Ana Sofía González Patiño, élève de dernière année à l'ENSC de Bordeaux INP

Dernière mise à jour : 27/11/2025

Entraînement du modèle YOLO11n sur la détection de personnes sur des images avec [une base de données sur Kaggle](https://www.kaggle.com/datasets/yusufberksardoan/traffic-detection-project).
Le code a été exécuté sur un [Notebook de Google Collab](https://colab.research.google.com/drive/1YLzi30TB_kMVyUncYiLLTTzC4LbRa2ti?usp=sharing) avec le GPU Tesla 4.

Commande d'installation des dépendances requises depuis le terminal :
pip install -r requirements.txt
