# person_detection_project
Projet de candidature stage de fin d'études chez Cali Intelligences
Fait par Ana Sofía González Patiño, ENSC - Bordeaux INP

Dernière mise à jour : 24/11/2025

Entraînement du modèle YOLO11n sur la détection de personnes sur des images avec une base de données sur Kaggle.

Commande d'installation des packages requis depuis le terminal :
pip install -r requirements.txt

Source vers la base de données :
https://www.kaggle.com/datasets/yusufberksardoan/traffic-detection-project
